# Script directory

This directory contains command-line entry points, Python support modules, and local checks.

- `run_*.sh`: launch entry points.
- `analyze_*.sh`: analysis entry points.
- `env.sh`: runtime environment variables.
- `setup_server.sh` and `download_data.sh`: setup and data helpers.
- `test_*.py`: automated checks.

Common shared modules are in `../fulltd/`. Runtime-generated files are not tracked here.
