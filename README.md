# reproduceSL

This repository contains Python source files, command-line utilities, automated tests, and third-party notices.

## Directory overview

- `agents/`: reusable Python components.
- `fulltd/`: shared data, model, and utility modules.
- `dscpuscripts/`: command-line workflows, supporting scripts, and tests.
- `scripts/`: environment and setup helpers.
- `tests/`: automated checks.
- `docs/licenses/`: retained third-party notices.
- `requirements-fulltd.txt`: environment dependencies.

Files created by running scripts are stored outside this repository.
